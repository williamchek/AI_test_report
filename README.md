# AI Test Report （AI幫你測）

A daily tech digest — in English, every item hands-on tested or read in full before it is written up.

## What's inside

- 🆕 **Open-source project tests** — trending new OSS projects, actually installed and run to verify their claims
- ✍️ **Tech article deep-dives** — new essays from prominent dev/AI voices, read cover to cover and analyzed
- 🛠️ **Agent skill tests** — useful AI agent skills, read fully and executed against real examples
- 🔌 **MCP tests** — new MCP servers, actually wired up and tried out

Principle: only publish what was verified by hand; failures and overhyped projects are reported honestly — that is the whole point of "tested for you".

## Articles

Long-form deep-research features, in English and Traditional Chinese: [articles/](articles/)

## How we score

- ⭐5 — every claim I tested checked out; I'd recommend it to a friend.
- ⭐4 — works, with caveats worth knowing.
- ⭐3 — interesting but rough; watch, don't adopt yet.
- ⭐2 — mostly hype; the demo is better than the product.
- ⭐1 — broken or misleading.
- No score — couldn't test (the reason is always stated).
